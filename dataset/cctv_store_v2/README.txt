CCTV store litter dataset v2 (10 classes). Real frames hand-reviewed; split by source:
train = street scenes A+C, store clips '3min' + 'real_life', synthetic, negatives
val   = store clip 'realistic' (same scene as 3min: used only to pick the epoch) + synthetic val
test  = store clip 'clear_recognizable' (unseen litter layout)
