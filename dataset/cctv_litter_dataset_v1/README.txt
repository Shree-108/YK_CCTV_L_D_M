CCTV LITTER DATASET V1
150 separate positive CCTV-style images + 60 separate hard-negative images.
13 litter classes. YOLO bounding-box labels included.

IMPORTANT: This is a SYNTHETIC STARTER DATASET for testing the training pipeline.
Do not use it as the only dataset for production. Add real CCTV frames and real annotations.
TACO is a useful real-world complementary source; it contains diverse outdoor litter images.
